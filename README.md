# Одод Карго · Хэрэглэгчийн апп

Expo (SDK 58) + Expo Router дээр бүтээгдсэн, Expo Go дээр шууд туршиж болох жишиг апп.

## Ажиллуулах

```bash
cd odod-cargo-app
npm install
npx expo start
```

Дараа нь утсан дээрх **Expo Go** аппаар QR кодыг уншуулна (ижил Wi-Fi сүлжээнд байна).

## Туршилтын горим

- Ачаа, нэхэмжлэл, мэдэгдлийн жишээг харах бол **88112233** дугаараар нэвтэрнэ. Өөр 8 оронтой дугаараар шинэ хэрэглэгчийн хоосон бүртгэлийг туршина.
- Нэвтрэх код **123456**. Алдааны төлөвийг **000000** кодоор туршина. Таван удаа буруу оруулбал шинэ код авна.
- «Тээврийн дугаар бүртгүүлэх» хэсгээс шинэ дугаар оруулна. Өмнөх бүртгэлийг турших бол **YT882731004CN** дугаарыг ашиглана.
- Бүртгэлийн дэлгэрэнгүйд «Туршилтын ачаа хүлээн авах» товчийг дарна. Багц үүсэхэд «Миний ачаа» хэсгийн «Замд буй» жагсаалтад шилжиж, мэдэгдэл нэмэгдэнэ.
- «Ачааны дэлгэрэнгүй» дэх туршилтын товчоор ачааг дараагийн төлөвт шилжүүлнэ. «Авахад бэлэн» болоход нэхэмжлэл үүсэж, «Хүлээлгэн өгсөн» төлөвт түүх рүү шилжинэ.
- «Эрээн дэх хаяг» дэлгэц албан ёсны сайтад нийтэлсэн хаягийг салбар, тээврийн төрлөөр харуулна. Facebook нэрээ оруулаад хаягаа бүтнээр нь хуулж болно. Захиалга батлахаас өмнө «Албан ёсны хаяг нээх» холбоосоор мэдээллээ тулгана.

Өгөгдөл болон мэдэгдлийн тохиргоог апп ажиллаж байх хугацаанд дугаар тус бүрээр хадгална. SMS, түлхэх мэдэгдэл, онлайн төлбөр, Cargo API нь бодит интеграц шаардана.

## Бүтэц

```
src/
  app/            # Expo Router дэлгэцүүд
    (tabs)/       # Нүүр, Миний ачаа, Мэдэгдэл, Профайл
  components/     # ui.js (Btn, Card, Badge, Sheet...), ParcelCard, TabBar
  data.js         # Жишээ өгөгдөл, ачааны төлөв
  store.js        # Нэвтрэлт, дугаар тус бүрийн туршилтын өгөгдөл
  workflow.js     # Тээврийн дугаар ба ачааны төлөвийн дүрэм
  theme.js        # Дизайн токенууд (.pen дизайнтай ижил)
```
